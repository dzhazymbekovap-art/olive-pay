# Платежи O-Live

Заявки на оплату и их согласование для команды Olive.

**Маршрут:** автор → операционный директор → управляющий директор → бухгалтерия → оплачено.
Отказ на любом шаге возвращает заявку автору с причиной.

## Как устроено

- `index.html` — всё приложение одним файлом: вход, заявки, согласование, отчёт по статьям, настройки.
- Данные хранятся в базе Olive (Supabase), в таблицах `pay_*`. Доступ только через серверные функции `pay_*` с токеном сессии; напрямую таблицы закрыты.
- Файлы служебных записок и счетов лежат в закрытом хранилище `pay-files`, выдаются по временной ссылке.
- Вход по email и паролю. Временный пароль задаёт администратор в «Настройках», сотрудник меняет его при первом входе.

## Обновление

Чтобы выпустить новую версию, замените `index.html` в ветке `main`. GitHub Pages обновит сайт за 1–2 минуты. Данные при этом не затрагиваются.
